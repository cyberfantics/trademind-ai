TradeMind AI combines trade signals, trading journals, PnL tracking, and an AI trading coach in one application.

The project consists of a Flutter mobile application and a separate Python engine responsible for market analysis, signal generation, risk controls, and exchange integration.

## ✨ Features

| Feature | Description |
|---|---|
| 📊 Trade Signals | View active and completed trades, entry prices, stop-loss levels, take-profit targets, and outcomes. |
| 📓 Trading Journal | Record trades and review trading activity. |
| 💹 Performance Tracking | Monitor profit and loss (PnL) and trading history. |
| 🤖 AI Trading Coach | Chat with Gemini-powered AI for trading-related assistance. |
| 📤 Signal Sharing | Share signals and AI conversations as text, images, and PDFs. |
| 🔗 Exchange Integration | Bybit market data and demo-trading integration. |
| 🔔 Discord Alerts | Receive trading notifications through Discord. |
| 🛡️ Risk Management | Position limits, daily-loss protection, and a trading kill switch. |

## 📂 Repository

This repository currently contains the project documentation and existing web scaffold files:

- `package.json`
- `server.js`
- `vercel.json`

The Flutter application source code and Python trading engine are maintained separately and are not included in this public repository.

## 🧪 Trading Mode

Paper trading is the default mode. Bybit demo-trading integration is also available for testing strategies without using real funds.

## ⚠️ Disclaimer

TradeMind AI is a software project for trading analysis and automation. It does not guarantee profits or provide personalized financial advice. Trading involves financial risk. Always evaluate strategies and understand the risks before using real funds.
